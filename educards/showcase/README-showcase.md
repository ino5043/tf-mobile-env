# EduCards — tf-mobile-env ショーケース

## 概要

EduCards は **tf-mobile-env**（モバイルアプリ開発向け Claude Code 標準環境パッケージ）の価値を示すために構築したデモアプリです。

パッケージが提供する全 23 コンポーネント（5 Agent, 8 Rule, 6 Skill, 4 Command）を自然に活用し、プロダクション品質の Flutter アプリケーションを短期間で構築しました。

## ターゲットオーディエンス

| ターゲット | 訴求ポイント |
|-----------|-------------|
| 開発者・テックリード | Clean Architecture、TDD、テストカバレッジ 80%+、ADR |
| 経営層・マネージャー | 開発効率、品質保証の自動化、工数削減 |
