EduCards を Android に入れる

暗記カードのアプリ EduCards の Android 版です。Google Play を通さずに配っているため、入れるときに少しだけ手順が増えます。

ダウンロード

最新版をダウンロード（約 20 MB）

ほとんどのスマホはこのファイルで動きます。古いスマホ用のファイルや、これまでの版は リリースの一覧 にあります。

必要なもの: Android 7.0 以降のスマホかタブレット。

このページか、上のリリースの一覧からだけダウンロードしてください。 ほかの人から送られてきた EduCards の APK ファイルは入れないでください。中身が書き換えられていても見分けられません。

入れ方

  1. スマホの Chrome でこのページを開き、「最新版をダウンロード」を押します。
  2. 「このファイルは有害な可能性があります」と出たら、「ダウンロード」を押します。APK ファイルにはいつも出る表示です。
  3. ダウンロードが終わったら、通知か Chrome の「ダウンロード」から EduCards-arm64-v8a.apk を開きます。
  4. 「この提供元のアプリを許可」の画面が出たら、許可を入れてから戻ります。
  5. 「インストール」を押します。
  6. 「Play プロテクト」の確認が出たら、「詳細」→「インストールする」を選びます。Google Play を通していないアプリにはいつも出る確認です。
  7. 入ったら、手順 4 で入れた「この提供元のアプリを許可」を切っておきます（設定 → アプリ → Chrome → 不明なアプリのインストール）。ほかのアプリが勝手に入るのを防げます。

ファイルが本物か確かめる（任意）

念のため確かめたいときは、次の 2 つを見比べます。

  • ファイルの指紋（SHA-256）: リリースのページにある SHA256SUMS.txt の値と、ダウンロードしたファイルの値が同じか。パソコンなら Windows は certutil -hashfile ファイル名 SHA256、Mac は shasum -a 256 ファイル名 で出せます。
  • 署名の証明書: どの版も同じ証明書で署名しています。証明書の SHA-256 は、リリースのページの説明と signing-certificate.txt に載せています。違う証明書の APK は、本物ではありません。

APK は GitHub の上で、公開しているコードから自動で作っています。どのコードから作ったかの証明（ビルドの出どころの証明）も GitHub に残しています。

AI でカードを作るには

カードを手で作る・学ぶ・進み具合を見るのは、AI がなくても使えます。テーマや画像、PDF からカードを作るときだけ、AI の会社の API キーが必要です。

AIキーを作るページメモ
Claudeconsole.anthropic.com使った分だけ料金がかかります
ChatGPTplatform.openai.comChatGPT の月額プラン（Plus など）とは別で、使った分だけ料金がかかります
Geminiaistudio.google.com無料の枠があります。無料の枠では、送った内容が Google のサービスの改善に使われることがあります
  1. アプリの「設定」を開き、「使うAI」を選びます。
  2. その AI の API キーを貼り付けて、保存のボタンを押します。
API キーはお金に結びつく大事な情報です。 人に送ったり、画面の写真を共有したりしないでください。キーはスマホの中に暗号化して保存し、選んだ AI の会社にだけ送ります。EduCards の作者を含め、ほかのところには送りません。 料金が心配なときは、AI の会社のページで使える金額の上限を決めておくと安心です。

知っておいてほしいこと

  • データはスマホの中だけにあります。 作ったカードや学習の記録は、どこにも送りません（AI でカードを作るときに、テーマや選んだファイルを AI の会社に送るのを除く）。
  • バックアップには入りません。 安全のため、スマホのバックアップや機種変更の引き継ぎからは外しています。機種変更やアプリを消す前に、デッキの画面の「デッキをエクスポート」でカードを書き出しておいてください。
  • アプリが使う許可は、インターネットと「つながっているかの確認」だけです。 連絡先や写真の一覧などを勝手に読むことはありません。画像や PDF は、あなたが選んだファイルだけを読みます。

新しい版に更新する・消す

  • 更新: このページから新しい版をダウンロードして、同じ手順で入れます。上書きされ、カードや設定はそのまま残ります。
  • 消す: アプリのアイコンを長押しして「アンインストール」を選びます。カードと API キーも一緒に消えます。

困ったとき

  • 「アプリはインストールされていません」と出る: 前に別の方法で入れた EduCards が残っていると出ます。一度消してから入れ直してください（先に「デッキをエクスポート」でカードを書き出してください）。
  • AI でカードが作れない: 設定で選んだ AI と、保存したキーの会社が合っているか、キーの残高や上限を確かめてください。
  • そのほか: GitHub の Issues で知らせてください。API キーは書かないでください。
