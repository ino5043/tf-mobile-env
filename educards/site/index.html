EduCards

覚えたいことをカードにして、忘れそうなころに出し直す暗記カードのアプリです。テーマや画像、PDF から AI でカードを作ることもできます。

ブラウザで試す（デモ）

入れずにそのまま試せます。作ったカードは、このブラウザの中にだけ保存されます。

AI でカードを作るときは、ご自分の API キーが必要です。共用のパソコンでは API キーを入れないでください。

デモを開く

Android で使う

入れ方とダウンロード

できること

  • 4 種類のカード（表と裏、穴埋め、4 択、手順を追う問題）
  • 覚え具合に合わせて、次に出す日を自動で決める（SM-2 という方法）
  • 読み上げを聞きながら覚える
  • 毎日の進み具合と、続けた日数を見る
  • AI（Claude・ChatGPT・Gemini から選べる）でカードを作る

EduCards は tf-mobile-env の見本アプリです。
