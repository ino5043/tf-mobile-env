## 1. コンテキスト

EduCards の中核機能である間隔反復（Spaced Repetition）のアルゴリズムを選定する必要がある。学習効率を最大化しつつ、実装がシンプルであることが求められる。

## 2. 決定

**SM-2 (SuperMemo 2) アルゴリズム**を採用する。純粋関数として CalculateNextReviewUseCase に実装し、TDD のメイン対象とする。

パラメータ:
- 初期 EaseFactor: 2.5
- 最小 EaseFactor: 1.3
- 難易度評価: Again(0), Hard(3), Good(4), Easy(5)
- 間隔: rep0 → 1日, rep1 → 6日, repN → 前回間隔 × EF

## 3. 理由

### 検討した代替案

| アルゴリズム | 利点 | 不採用理由 |
|------------|------|----------|
| SM-18 (最新版) | より正確 | 特許あり、実装が複雑 |
| FSRS | データ駆動 | 学習データが必要、初期精度が低い |
| Leitner System | シンプル | 間隔が固定的、適応性が低い |
| Anki の修正 SM-2 | 実績あり | Anki 固有の拡張が多く複雑 |

SM-2 を選んだ理由:
- **実績**: 30年以上の研究に裏打ちされた効果
- **シンプル**: 純粋関数 1 つで実装可能（約 50 行）
- **テスト容易性**: 外部依存なし、すべての入出力が決定論的
- **特許フリー**: 自由に使用可能

## 4. 結果・影響

| 観点 | 影響 |
|------|------|
| ✅ 学習効率 | 科学的に裏付けされた最適な復習間隔 |
| ✅ テスト | 17 件の境界値テストで品質保証 |
| ✅ 実装 | 約 50 行の純粋関数、バグの入りにくい設計 |
| ⚠️ 適応性 | 個人差への適応は EaseFactor 調整のみ |
| ⚠️ 初期段階 | 最初の数回は固定間隔で、パーソナライズに時間がかかる |
