## 1. コンテキスト

EduCards はフラッシュカード学習アプリであり、ネットワーク接続なしでも全機能が動作する必要がある。ローカルデータベースの選定が必要。

## 2. 決定

**Hive** (v2.x) をローカルデータベースとして採用し、Cache First 戦略でオフラインファースト設計を実現する。

## 3. 理由

### 検討した代替案

| DB | 利点 | 不採用理由 |
|----|------|----------|
| SQLite (sqflite) | SQL クエリ、成熟 | Flutter Web 非対応 |
| Isar | 高速、型安全 | Web サポートが不安定 |
| SharedPreferences | シンプル | 構造化データに不向き |
| Drift | 型安全 SQL | Web 対応に追加設定が必要 |

Hive を選んだ理由:
- **Web 互換**: `hive_flutter` で IndexedDB バックエンドに自動切り替え
- **高速**: バイナリ形式で読み書きが高速（SQLite より軽量な操作）
- **型安全**: TypeAdapter でカスタム型を保存可能
- **ゼロ依存**: ネイティブライブラリ不要で全プラットフォーム動作

## 4. 結果・影響

| 観点 | 影響 |
|------|------|
| ✅ オフライン | ネットワーク不要で全機能動作 |
| ✅ Web 対応 | Flutter Web ビルドでそのまま動作 |
| ✅ パフォーマンス | 小規模データで高速 |
| ⚠️ クエリ制限 | 複雑なクエリは自前実装が必要 |
| ⚠️ マイグレーション | スキーマ変更時の対応が手動 |
