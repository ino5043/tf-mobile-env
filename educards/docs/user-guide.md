# EduCards ユーザーガイド

## EduCards とは

EduCards は、フラッシュカードを使った間隔反復学習アプリです。
科学的に証明された SM-2 アルゴリズムにより、最適なタイミングで復習を促し、効率的な記憶定着を支援します。

---

## ペルソナ定義

### ペルソナ 1: 親（コンテンツ作成者）

| 項目 | 内容 |
|------|------|
| 名前 | 太郎（仮） |
| 役割 | 家庭内の学習コンテンツ管理者 |
| 目的 | 子供の学習を支援するデッキを作成・管理する |
| 利用場面 | 週末にまとめてデッキを準備、子供の進捗を確認 |
| 技術レベル | アプリ操作に慣れている、API キー設定も可能 |

**主なユースケース:**
- 教科書の内容をもとに漢字・英単語デッキを手動作成
- CSV ファイルで問題集を一括インポート
- Claude AI でトピック指定して自動生成
- 子供の進捗を Progress タブで確認
- デッキを JSON エクスポートしてバックアップ

### ペルソナ 2: 子供（学習者）

| 項目 | 内容 |
|------|------|
| 名前 | 花子（仮） |
| 役割 | 学習者 |
| 目的 | 毎日少しずつカードを復習して知識を定着させる |
| 利用場面 | 毎朝 10 分、寝る前 10 分 |
| 技術レベル | タップ操作ができる程度 |

**主なユースケース:**
- 親が用意したデッキで学習（Study Now）
- 自分の正解率やストリークを確認してモチベーション維持
- 慣れてきたら自分でカードを追加

### ペルソナ 3: 社会人学習者（自己学習）

| 項目 | 内容 |
|------|------|
| 名前 | あなた自身 |
| 役割 | 技術学習者 |
| 目的 | 技術トピック（クラウド、プログラミング等）の知識を効率的に定着 |
| 利用場面 | 通勤時間、隙間時間 |
| 技術レベル | 高い |

**主なユースケース:**
- Claude AI で「Terraform 基礎」「Kubernetes コマンド」等のデッキを自動生成
- 学習中に気づいた補足カードを手動追加
- 進捗トレンドで学習習慣を可視化
- 1 日の上限を設定して無理なく継続

## 画面構成

```
[Decks]        [Study]        [Progress]
  |               |                |
  |               |                |
デッキ一覧    今日の学習計画    進捗ダッシュボード
```

アプリ下部の 3 つのタブで主要画面を切り替えます。

## 基本操作

### 1. デッキを作成する

#### 手動入力

1. Decks タブの **＋ボタン** をタップ
2. タイトルと説明を入力
3. 「Manual」タブでカードを 1 枚ずつ追加
   - **Front**: 問題文（例: 「apple の意味は？」）
   - **Back**: 答え（例: 「りんご」）
4. 必要な枚数を追加したら **Save Deck** をタップ

#### CSV/JSON ファイルからインポート

1. デッキ作成画面の「Import」タブを選択
2. **Choose File** をタップ
3. CSV または JSON ファイルを選択

**CSV 形式:**
```csv
front,back
apple,りんご
banana,バナナ
orange,オレンジ
```

**JSON 形式:**
```json
[
  {"front": "apple", "back": "りんご"},
  {"front": "banana", "back": "バナナ"}
]
```

#### AI で自動生成

1. デッキ作成画面の「AI Generate」タブを選択
2. Settings で **Claude API Key** を設定済みであること
3. トピック（例: 「日本の歴史 - 戦国時代」）を入力
4. カード枚数（5〜30 枚）とレベル（Easy / Medium / Hard）を選択
5. **Generate** をタップ → 数秒で生成完了

### 2. デッキの詳細を見る

1. Decks タブでデッキカードをタップ
2. デッキ詳細画面が表示される:
   - カード総数、復習期限カード数、習熟度
   - 全カード一覧（習熟度バッジ付き）

### 3. 学習する

#### デッキ詳細から学習

1. デッキ詳細画面で **Study Now** をタップ
2. カードの表（問題）が表示される
3. 答えを考えたらタップして裏面を確認
4. 自己評価を選択:
   - **Again**: 全く分からなかった → 10 分後に再出題
   - **Hard**: 少し迷った → 短い間隔で再出題
   - **Good**: 正解した → 適切な間隔で再出題
   - **Easy**: 簡単だった → 長い間隔で再出題

#### 学習計画タブから学習

1. Study タブを開く
2. 今日の学習キュー（新規カード＋復習カード）が表示される
3. 1 日の上限を超えたカードは翌日以降に持ち越し

### 4. デッキを編集する

1. デッキ詳細画面の **編集アイコン（鉛筆）** をタップ
2. 編集画面でできること:
   - **タイトル・説明の変更**
   - **既存カードの編集**: 鉛筆アイコンをタップ → 内容を修正 → Done
   - **カードの削除**: ゴミ箱アイコンをタップ
   - **新規カードの追加**: 画面下部の Add Card フォーム
3. **Save** で保存

> **SR データの扱い:**
> - 答え（Back）の修正 → 学習進捗はそのまま保持
> - 問題（Front）の変更 → 学習進捗がリセットされます（警告表示あり）
> - 新規カード → 初期状態から学習開始

### 5. 進捗を確認する

Progress タブには 3 つのサブタブがあります:

#### Overview（概要）

- **ストリーク**: 連続学習日数（現在 / 最長）
- **今日の統計**: 学習カード数、正解数、正答率
- **習熟度分布**: 円グラフ（New / Learning / Review / Mastered）

#### Trend（推移）

- 直近 7 日間の学習推移（積み上げ棒グラフ）
  - 緑: 正解数
  - オレンジ: 不正解数
- 期間合計: 総学習数、総正解数、平均正答率

#### By Deck（デッキ別）

- 各デッキの習熟度内訳
- どのデッキに注力すべきかが一目でわかる

### 6. デッキをエクスポートする

1. デッキ詳細画面の **エクスポートアイコン（↓）** をタップ
2. JSON 形式でデッキ内容が表示される
3. **Copy to Clipboard** でコピー → メモ帳やファイルに貼り付けて保存

エクスポートされる内容:
```json
{
  "title": "英単語 初級",
  "description": "中学1年レベルの基本単語",
  "exportedAt": "2026-03-15T10:30:00.000",
  "cards": [
    {"front": "apple", "back": "りんご"},
    {"front": "book", "back": "本"}
  ]
}
```

> 学習進捗（SR データ）はエクスポートに含まれません。
> エクスポートした JSON は、別の端末でインポートして使えます。

### 7. 設定を変更する

AppBar の歯車アイコンから Settings 画面を開きます。

| 設定項目 | 説明 | デフォルト |
|---------|------|-----------|
| Daily New Card Limit | 1 日に学習する新規カードの上限 | 10 枚 |
| Daily Review Card Limit | 1 日に復習するカードの上限 | 20 枚 |
| Claude API Key | AI デッキ生成に使用する API キー | 未設定 |

> **Claude API Key の取得方法:**
> 1. https://console.anthropic.com にアクセス
> 2. API Keys ページで新しいキーを作成
> 3. 生成されたキー（`sk-ant-...`）をコピーして Settings に貼り付け

## 学習のコツ

### 毎日少しずつが最も効果的

SM-2 アルゴリズムは「忘れかけたタイミング」で復習することで記憶を強化します。
1 日 10〜15 分を毎日続けることが、週末にまとめて 2 時間やるよりも効果的です。

### 推奨する学習リズム

| 時間帯 | やること |
|--------|---------|
| 朝（5〜10 分） | Study タブから復習カードを消化 |
| 夜（5〜10 分） | 残りの復習 + 新規カードに挑戦 |

### 自己評価は正直に

- 少しでも迷ったら **Hard** を選ぶ
- 完全に思い出せたら **Good**
- 見た瞬間にわかったら **Easy**
- 全くわからなかったら **Again**

正直な評価がアルゴリズムの精度を上げ、結果的に学習効率が向上します。

### デッキは 20〜50 枚が最適

- 少なすぎると学習効果が薄い
- 多すぎると 1 日の復習量が膨れ上がる
- 大きなトピックは複数デッキに分割する

## トラブルシューティング

| 症状 | 対処 |
|------|------|
| AI 生成が動かない | Settings で Claude API Key が設定されているか確認 |
| ファイルインポートが失敗する | CSV は `front,back` のヘッダー行があるか確認。JSON は配列形式 `[{...}]` か確認 |
| 学習カードが表示されない | 復習期限のカードがない場合は「No cards due」と表示される。新規カードを追加するか翌日まで待つ |
| データが消えた | ブラウザのキャッシュを削除すると Hive データが消えます。定期的にエクスポートしてバックアップを取ってください |
